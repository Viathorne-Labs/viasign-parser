# Contributing

ViaSign Parser is an early, review-required accessibility prototype.

Contributions must be small, test-backed, public-safe, and clear about
uncertainty. Do not submit private lesson materials, copied classroom examples,
community media, personal review data, or claims of final SgSL correctness.

Before changing behavior:

1. Add an independently authored fixture or focused test.
2. Confirm it fails for the intended reason.
3. Implement the smallest safe change.
4. Run `python -m pytest`.
5. Update boundary documentation when scope changes.

All parser results must remain review-required and not motion-ready.

Unless explicitly stated otherwise, contributions submitted for inclusion are
licensed under Apache-2.0, matching the repository license.
