# Security Policy

The supported code is the latest state of the main branch after public release.
No release exists yet.

Report vulnerabilities privately through the repository owner's designated
security contact once available. Do not attach private source material,
personal data, or community media to a public issue.

In-scope concerns include accidental private-data inclusion, unsafe API output,
loss of review/readiness invariants, request logging, dependency problems, and
routes that cross the documented public boundary.

This prototype is not suitable for emergency, legal, medical, or certified
interpretation.
