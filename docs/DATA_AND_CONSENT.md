# Data and Consent Boundary

This repository accepts code and independently authored synthetic text
fixtures. It does not accept private linguistic sources or personal media.

Do not submit:

- classroom notes, lesson PDFs, screenshots, or copied exercises
- teacher feedback without explicit publication permission
- private Deaf community discussions or knowledge records
- identifiable reviewer notes
- sign recordings, contributor videos, voice, images, or biometric material
- private annotations, corpora, or sign-bank material
- generated derivatives of material that was not cleared for publication

Public examples must include a provenance note stating that they were
independently authored for this repository or identifying a compatible public
license and required attribution.

Consent to review a result is not consent to publish the reviewer's identity,
words, image, signing, or recording.
